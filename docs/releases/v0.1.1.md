# SerialPilot v0.1.1

这是面向真实硬件测试的 Windows 桌面版本。

## 主要变化

- 桌面程序默认枚举并打开系统真实 COM 串口，不再使用 Mock 适配器。
- stdio 和 Streamable HTTP MCP 服务均使用同一套真实串口核心。
- Mock 适配器仅编译进 Rust 自动化测试，不进入发行版运行路径。
- 保留文本、HEX、Base64、文件发送、RX 游标读取、超时等待、交换事务和波形功能。

## 下载

普通用户下载 `serialpilot.exe` 即可运行；MCP 客户端只有在需要独立 MCP 进程时才使用对应的 MCP 可执行文件。

## 已知限制

- 当前发行版优先支持 Windows COM 设备，设备驱动和权限仍由系统负责。
- 当前附件为免安装桌面 EXE，暂未提供 MSI/NSIS 安装包。
