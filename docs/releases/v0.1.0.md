# SerialPilot v0.1.0

这是 SerialPilot 的首个可运行垂直切片版本，面向 Windows 桌面端真实串口使用。

## 本次发布

- Tauri 2 + React + TypeScript + Rust 桌面工作区。
- 系统真实串口适配器，枚举并打开 Windows COM 端口。
- 文本、HEX、Base64 和文件发送。
- RX 后台缓冲、游标读取、超时等待和请求-响应交换。
- MCP stdio 与 Streamable HTTP 服务，串口和波形工具共用 Rust 核心命令路径。
- 多通道波形、自定义名称和颜色、悬浮采样值、拖拽平移、滚轮平移、横轴缩放和最新数据跟随。
- 深色/浅色主题和可调整大小的桌面三栏工作区。

## 下载

普通用户下载并运行 `serialpilot.exe` 即可，不需要单独启动 MCP 可执行文件。

MCP 客户端需要独立进程时再使用：

- `serialpilot-mcp.exe`：stdio 传输。
- `serialpilot-mcp-http.exe`：Streamable HTTP 传输。

## 已知限制

- 当前优先支持 Windows 真实串口；不同平台的设备驱动能力可能不同。
- 当前发布附件为免安装桌面 EXE；MSI/NSIS 安装包需要额外的 Windows 打包工具下载。
- 会话审计暂存于内存，SQLite 持久化尚未加入。
