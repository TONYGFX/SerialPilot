# SerialPilot v0.1.3

这是一次面向日常串口调试、文件传输和桌面工作区体验的功能更新。

## 主要更新

- 新增完整文件接收流程：Xmodem、Xmodem-1k 与 Ymodem 支持发送和接收，包含进度、取消、重传、完成记录和文件定位。
- 文件传输卡片改为固定区域内的记录列表，传输中的取消操作不会挤压文件名或改变主控件位置。
- 终端文本收发支持 UTF-8、GBK、ASCII 与 UTF-16LE；HEX 输入自动过滤非法字符并按字节分组显示。
- 波形监视器支持时间轴缩放、平移、跟随最新数据、采样点悬浮查看和 TXT 导出；曲线改为单调平滑插值，峰谷不会产生额外过冲。
- 增加深色、浅色与跟随系统主题，以及集中式设置页、快捷键和默认接收目录配置。
- 增加应用更新提示：优先使用 Gitea 读取版本，失败时回退 GitHub；发现新版本后可直接打开对应的 GitHub Release。
- 持续优化串口重连、连续数据分帧、文件传输握手以及终端滚动、筛选与布局细节。

## MCP

- MCP 支持 stdio 与 Streamable HTTP。
- 串口批量发送、批量事务、等待任一条件、端口监测和主动重连均可通过 MCP 调用。
- 波形通道支持通过 MCP 列表、添加、修改、删除和清空样本。

## 下载说明

- `serialpilot.exe`：Windows x64 绿色版，可直接运行。
- `SerialPilot_0.1.3_x64-setup.exe`：Windows x64 NSIS 安装包。
- `SerialPilot_0.1.3_x64_en-US.msi`：Windows x64 MSI 安装包。

`serialpilot-mcp.exe` 和 `serialpilot-mcp-http.exe` 仅供需要独立运行 MCP 服务的用户使用，普通桌面用户只需运行 `serialpilot.exe`。
